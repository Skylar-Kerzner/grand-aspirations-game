# Grand Aspirations

make an idle tycoon game where you work and then invest in different things that give you appreciation. Some are predictable, some are variable and some have flat value, and do or can depreciate. But essentially you have a few tiers of potential aesthetic for each of the visual things you can buy like clothes, car, house, various kinds of businesses in various sectors, hotel, city, theme park, restaurant, etc. Be creative. Theres costs like food rent and theres loans but having better stuff should have benefits. Theres investments, and investing in businesses, hiring a manager for the business, consultants, make lots of ways to make money, and also make it very visually rewarding to finally attain those tiers by having visual assets that are lovely to see once you get to that level of each thing. Dont be shy about creating a lot of visual assets with ai generation, dont use emojis.
